# Ayrat Services

Одностраничный статический сайт (HTML/CSS/JS, без фреймворков и сборки) для услуги
перевозки лежачих больных.

## Статус

Проект только что создан (репозиторий + структура), контент ещё не наполнен. Нужны от
заказчика: точное название компании/ИП, город/география обслуживания, телефон,
мессенджеры для связи (WhatsApp/Telegram), перечень услуг и тарифы, наличие
спецтранспорта/оборудования, юридические реквизиты для политики конфиденциальности.

## Структура (план)

- `index.html` — единственная страница сайта
- `politika-konfidentsialnosti.html` — политика обработки персональных данных (152-ФЗ)
- `css/style.css` — дизайн-система
- `js/main.js` — интерактивность, форма заявки, cookie-баннер
- `assets/` — изображения
- `robots.txt`

## Как открыть локально

```
npx serve .
```
