# Везём Лёжа

Одностраничный статический сайт (чистые HTML/CSS/JS, без фреймворков и сборки) для
службы перевозки лежачих больных.

**Живой сайт:** https://mihailburmasov.github.io/Ayrat_Services/
**Репозиторий:** https://github.com/mihailburmasov/Ayrat_Services

## Статус

Сайт свёрстан пиксель-в-пиксель по дизайн-макету заказчика и задеплоен на GitHub Pages.
Контент (тексты, телефон, цены) взят из макета — актуальность нужно свежим взглядом
сверить с заказчиком перед стартом рекламы (см. «Что нужно уточнить у заказчика» ниже).

## Структура

- `index.html` — вся разметка страницы (шапка, hero, услуги, цены, преимущества, шаги,
  футер)
- `css/style.css` — все стили; дизайн-токены (цвета, шрифт, отступы) объявлены в
  `:root` в начале файла
- `js/main.js` — мобильное меню (бургер) и подстановка текущего года в футер
- `assets/` — изображения:
  - `hero-transport.jpg`, `price-city.jpg`, `price-road.jpg` — фото заказчика
  - `logo-header.png`, `logo-footer.png` — логотип (светлый/тёмный вариант) с
    прозрачным фоном
  - `icons/` — иконки услуг, преимуществ, шагов и кнопок, нарезанные из фирменного
    набора заказчика

## Источник дизайна

Исходники макета (референсное изображение, HTML-прототип, оригинальные фото и иконки
одним файлом на несколько штук) лежат вне репозитория, на диске:
`D:\Claude\Projects\Perevozka\`. Если понадобится что-то перепроверить или пересобрать —
все точные значения цветов/шрифтов/отступов задокументированы в

Шрифт — **PT Sans** (Google Fonts, начертания 400/700), подключён через
`<link>` в `index.html`.

## Как открыть локально

```
npx serve .
```

## Как обновить и задеплоить

Сайт раздаётся GitHub Pages прямо из ветки `main` (корень репозитория), билд-шаг не
нужен — после `git push` изменения появляются на живом сайте через 1–2 минуты.

```
git add -A
git commit -m "..."
git push origin main
```

## Что нужно уточнить у заказчика

- Актуальность цен (3500 ₽ по городу, 70 ₽/км межгород) и телефона
- Точное юридическое название/реквизиты — для футера и будущей политики
  конфиденциальности
- Реальную географию обслуживания (сейчас в футере «ПО ВСЕЙ РОССИИ» — так ли это)
- WhatsApp/Telegram, если нужны дополнительные каналы связи помимо звонка
- Лицензии/сертификаты, если есть — можно добавить блок доверия
